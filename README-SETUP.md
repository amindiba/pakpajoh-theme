# راهنمای محتوا و تنظیمات نهایی (پاک‌پژوه)
۱. **تنظیم منوها:** پیشخوان > نمایش > منوها. منوی اصلی شامل: خانه، درباره ما، خدمات، ماشین‌آلات، مراحل همکاری، تماس با ما.
۲. **ثبت خدمات:** پیشخوان > خدمات > افزودن. (عنوان، تصویر شاخص، توضیحات کوتاه و ترتیب).
۳. **ثبت ماشین‌آلات:** پیشخوان > ماشین‌آلات > افزودن.
۴. **سئو (Rank Math):** برای هر برگه، عنوان و توضیحات متا را ویرایش کنید. (طولانی نباشد).
۵. **محتوای صفحات:** درباره ما، تماس، مراحل همکاری را از ویرایشگر صفحه تکمیل کنید.
