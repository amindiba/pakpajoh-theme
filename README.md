# قالب اختصاصی شرکت پاک‌پژوه (PakPajoh Modern)

**نسخه:** ۳.۰ | **وضعیت:** در حال توسعه (کدنویسی کامل و اختصاصی)

---

## 📖 معرفی پروژه
این مخزن شامل سورس‌کد قالب اختصاصی وردپرس برای **شرکت پاک‌پژوه** است. این قالب از صفر و با کدنویسی کامل (PHP, CSS, JS) برای دستیابی به بالاترین سطح سرعت، امنیت، سئو و طراحی پریمیوم ساخته می‌شود. هیچ افزونه‌ای برای قابلیت‌های اصلی (انیمیشن، امنیت، سئو) استفاده نمی‌شود.

- **نام برند:** شرکت پاک‌پژوه (PakPajoh)
- **نام قانونی:** آتیه مهرگان انعکاس (شماره ثبت: ۶۳۸۲۱۷)
- **شعار:** درخشش در عمل
- **دامنه:** [pakpajoh.ir](https://pakpajoh.ir)
- **آدرس:** تهران، خیابان کریمخان، کوچه آبگان، پلاک ۴، واحد ۱
- **تلفن‌ها:** ۰۲۱-۹۱۰۹۲۱۲۳ | ۰۹۱۲۱۱۵۶۸۶۸ | ۰۹۱۲۲۰۸۸۱۵

## 🎨 مشخصات طراحی (Design System)
- **پالت رنگی:** مینیمال پریمیوم (گرافیتی `#2D2D2D`، طلایی `#C9A227`، پس‌زمینه روشن `#FAFAF7`).
- **فونت:** Vazirmatn (لوکال)
- **جهت:** RTL
- **اصول:** مینیمال، پریمیوم، بدون ایموجی در UI، اعداد فارسی، انیمیشن‌های نرم و مدرن.

## 📂 ساختار پوشه‌ها و فایل‌ها
```text
pakpajoh/
├── assets/
│   ├── css/          # main.css (استایل اصلی)
│   ├── js/           # app.js (اسکریپت‌های تعاملی)
│   ├── images/       # تصاویر قالب
│   └── fonts/        # فونت Vazirmatn
├── inc/              # فایل‌های PHP برای عملکرد قالب
├── template-parts/   # بخش‌های قابل استفاده مجدد
├── functions.php     # توابع اصلی قالب
├── header.php        # هدر
├── footer.php        # فوتر
├── front-page.php    # صفحه اصلی
├── index.php         # فالبک
├── page.php          # قالب برگه پیش‌فرض
├── single.php        # قالب نوشته تکی
├── 404.php           # صفحه ۴۰۴
└── README.md         # همین فایل
```

## 🛠 نصب و راه‌اندازی
1. پوشه `pakpajoh` را در `wp-content/themes/` قرار دهید.
2. از پیشخوان، قالب **PakPajoh Modern** را فعال کنید.
3. به **تنظیمات > پیوندهای یکتا** بروید و ذخیره کنید.
4. از **نمایش > منوها** منوی اصلی و فوتر را بسازید.
5. در **تنظیمات > خواندن** صفحه اصلی را انتخاب کنید.
