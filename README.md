## 📖 معرفی پروژه
این مخزن شامل سورس‌کد قالب اختصاصی وردپرس برای **شرکت پاک‌پژوه** است. این قالب از صفر و با کدنویسی کامل (PHP, CSS, JS) برای دستیابی به بالاترین سطح سرعت، امنیت، سئو و طراحی پریمیوم ساخته می‌شود. هیچ افزونه‌ای برای قابلیت‌های اصلی (انیمیشن، امنیت، سئو) استفاده نمی‌شود.

- **نام برند:** شرکت پاک‌پژوه (PakPajoh)
- **نام قانونی:** آتیه مهرگان انعکاس (شماره ثبت: ۶۳۸۲۱۷)
- **شعار:** درخشش در عمل
- **دامنه:** [pakpajoh.ir](https://pakpajoh.ir)
- **آدرس:** تهران، خیابان کریمخان، کوچه آبگان، پلاک ۴، واحد ۱
- **تلفن‌ها:** ۰۲۱-۹۱۰۹۲۱۲۳ | ۰۹۱۲۱۱۵۶۸۶۸ | ۰۹۱۲۲۰۸۸۱۵

## 🎨 مشخصات طراحی (Design System)
- **پالت رنگی:** مینیمال پریمیوم (گرافیتی `#2D2D2D`، طلایی `#C9A227`، پس‌زمینه روشن `#FAFAF7`).

## 🛠 نصب و راه‌اندازی
1. پوشه `pakpajoh` را در `wp-content/themes/` قرار دهید.
2. از پیشخوان، قالب **PakPajoh Modern** را فعال کنید.
3. به **تنظیمات > پیوندهای یکتا** بروید و ذخیره کنید.
4. از **نمایش > منوها** منوی اصلی و فوتر را بسازید.
5. در **تنظیمات > خواندن** صفحه اصلی را انتخاب کنید.

## 🎨 مشخصات طراحی نهایی (Design System)

### پالت رنگی (صنعتی مدرن با تاکید مس)
| نقش | کد HEX | استفاده |
|---|---|---|
| Background روشن | `#F4F6F8` | پس‌زمینه اصلی سایت |
| Surface | `#FFFFFF` | پس‌زمینه کارت‌ها |
| Primary | `#0A2540` | آبی نفتی (هدر، فوتر، متن) |
| Secondary | `#1E3A5F` | آبی سلطنتی (گرادیانت‌ها) |
| Accent | `#C9A96E` | مس/طلایی (دکمه‌ها، لینک‌ها) |
| Accent Hover | `#B08D5A` | مس تیره‌تر |
| Text Muted | `#5A6B7D` | متن ثانویه |
| Border | `#E0E4E8` | خطوط جداکننده |
| Success | `#4A9B68` | سبز (نشانگرهای مثبت) |

### آیکون‌ها (Icons)
- **منبع:** Lucide Icons (lucide.dev)
- **استایل:** Outline (خطی)
- **ضخامت:** 1.5px
- **رنگ:** Accent (مس) برای آیکون‌های اصلی، Primary (آبی نفتی) برای ثانویه
- **انیمیشن:** فقط برای دکمه‌ها و لینک‌ها (حرکات ظریف)

### تایپوگرافی
- **فونت:** Vazirmatn (لوکال)
- **سلسله‌مراتب:** H1: 3rem, H2: 2.5rem, H3: 1.5rem, Body: 1rem, Small: 0.9rem

### انیمیشن‌ها
- **اسکرول:** IntersectionObserver با مدت 1.2s و easing `cubic-bezier(0.25, 1, 0.5, 1)`
- **هاور:** تغییرات ملایم (سایه، رنگ، جابجایی 2-5px)
- **هدر:** کاهش ارتفاع هنگام اسکرول (0.4s)

### چیدمان
- **Container:** 1600px
- **Grid:** 12 ستونه
- **فاصله‌ها:** 4/8/12/16/24/32/48/64/96 (بر اساس مقیاس 8px)
