# PakPajoh A4Site Theme

قالب بلوکی پریمیوم اختصاصی شرکت پاک‌پژوه (آتیه مهرگان انعکاس) — FSE، RTL، سازگار با Rank Math.

## نصب

1. پوشه را در `wp-content/themes/pakpajoh_a4site_theme` قرار دهید یا فایل ZIP را از **نمایش > پوسته‌ها > افزودن پوسته > بارگذاری** آپلود کنید.
2. پوسته را فعال کنید.
3. فونت وزیرمتن را از [این لینک](https://github.com/rastikerdar/vazirmatn/releases) دانلود کرده و فایل `Vazirmatn-Variable.woff2` را در `assets/fonts/` قرار دهید.

## راه‌اندازی اولیه

پس از فعال‌سازی، با نقش **Administrator** به آدرس زیر بروید:
/wp-admin/?pakpajoh_setup=1

text

این کار به صورت خودکار صفحات (خانه، خدمات، نمونه‌کارها، درباره ما، تماس) و منوی اصلی را می‌سازد و صفحه «خانه» را به عنوان صفحه اصلی تنظیم می‌کند.

پس از اجرا، فایل `inc/one-time-setup.php` و خط `require_once` آن را از `functions.php` حذف کنید.

## منوها

- **منوی اصلی:** نمایش > فهرست‌ها — اختصاص به موقعیت «منوی اصلی».
- **منوی فوتر:** نمایش > فهرست‌ها — اختصاص به موقعیت «منوی فوتر».

## الگوهای بلوکی (Patterns)

از ویرایشگر بلوک، دسته «پاک‌پژوه» را باز کرده و هر الگو را وارد کنید:

| الگو | کاربرد |
|---|---|
| هیرو اصلی | بخش ابتدایی صفحه اصلی |
| تعهدات ما | سه ستون ارزش‌های کلیدی |
| خدمات اصلی | گرید شش‌تایی خدمات |
| نمونه‌کارها | گالری تصویری پروژه‌ها |
| نظرات مشتریان | چیدمان دو ستونه بازخوردها |
| فرآیند کار | چهار مرحله اجرا |
| دعوت به اقدام | CTA نهایی |

## تمپلیت‌ها

| فایل | کاربرد |
|---|---|
| `front-page.html` | صفحه اصلی — همه الگوها به ترتیب |
| `page.html` | برگه‌های داخلی |
| `single.html` | نوشته تک |
| `archive.html` | آرشیو نوشته‌ها |
| `404.html` | صفحه خطا |
